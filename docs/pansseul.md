# 판쓸 규칙과 검증

## 공식 자료 재검증 결과

판쓸의 기본 조건과 피 보상은 아래 공식 가이드에서 확인했습니다. 다른 특수 이벤트와의 중복 보상은 공식 자료로 확인되지 않았으며, 이 프로젝트에서는 사용자의 결정에 따라 합산을 명시적인 하우스 룰로 채택합니다. 이 문서는 위키류 자료를 규칙 근거로 사용하지 않습니다.

| 항목 | 공식 자료에서 확인한 내용 |
| --- | --- |
| 판쓸 조건 | 바닥패를 모두 가져오는 경우. 피망은 손패를 내고 더미패를 뒤집는 과정을 명시합니다. |
| 기본 보상 | 상대 피 1장. 한게임 맞고·고스톱 가이드에 모두 안내되어 있습니다. |
| 마지막 패 | 피망은 자신의 마지막 패에서 판쓸 피를 가져오지 않는다고 명시합니다. |
| 판쓸 + 쪽 / 따닥 / 뻑 회수 / 자뻑 회수 / 폭탄 | 개별 이벤트의 보상은 안내되어 있으나 동시 발생 시 합산·비합산·우선순위는 확인하지 못했습니다. |

각 이벤트의 보상이 별도로 나열되어 있다는 사실만으로 공식 서비스의 중복 합산 여부를 추론하지 않습니다. 아래 합산 규칙의 근거는 공식 가이드가 아니라 이 프로젝트의 하우스 룰 결정입니다.

## 프로젝트 하우스 룰 — 중복 보상 합산

- 2인 맞고와 3인 고스톱 모두, 판쓸과 쪽·따닥·뻑 회수·자뻑 회수·폭탄 등 다른 피 획득 이벤트가 같은 턴에 동시에 발생하면 각 이벤트의 피 보상을 합산합니다.
- 예: 쪽+판쓸은 상대별 2피, 따닥+판쓸은 상대별 2피, 자뻑 회수+판쓸은 상대별 3피입니다. 폭탄 보상을 먼저 지급한 뒤 같은 턴의 판쓸 보상을 더하는 경로에도 적용합니다.
- **이는 공식 서비스에서 확인된 규칙이 아니라 이 프로젝트에서 확정한 하우스 룰입니다.**
- 각 이벤트의 보상 제외 조건은 유지합니다. 자신의 마지막 차례에는 판쓸 보상 0피를 더하며, 기존 다른 이벤트의 보상을 변경하지 않습니다.

## 현재 구현에 적용하는 방식

- 손패와 더미패 처리, 필요한 패 선택까지 끝난 뒤 실제 획득 패가 있고 바닥이 비면 판쓸입니다. 빈 바닥에서 쪽으로 자신이 낸 패를 회수한 경우도 포함합니다.
- 2인 맞고는 상대에게서 1피, 3인 고스톱은 다른 두 사람에게서 각각 1피를 가져옵니다. 별도 점수나 정산 배수는 추가하지 않습니다.
- 자신의 마지막 차례에는 판쓸 피 보상을 추가하지 않습니다. `판쓸!` 표시는 유지합니다. 전체 게임의 마지막 플레이어인지가 아니라 자신의 남은 차례를 기준으로 합니다.
- 이 프로젝트에서 남은 차례는 처리 후 `손패 수 + 폭탄 패스 수`로 표현합니다. 폭탄 패스가 남아 있으면 손패가 없어도 마지막 차례가 아닙니다.
- 기존 피 가져오기 함수대로 일반 피를 우선하며, 일반 피가 없으면 쌍피를 가져옵니다. 피가 부족하면 있는 만큼만 가져옵니다.

## 근거와 적용 범위

- [한게임 신맞고 공식 가이드](https://mgostop.hangame.com/guide/combine/02_02_rule.html): 바닥패를 모두 가져오는 판쓰리와 상대 피 1장 보상.
- [한게임 고스톱 공식 가이드](https://hangame-images.toastoven.net/hangame/pc/gostop/introduce/html/ssgostop/guide_ssgostop03_02.html): 판쓰리 조건과 상대 피 1장 보상. 개별 뻑 회수·따닥·폭탄·쪽 보상도 설명하지만 판쓰리와의 중복 지급은 명시하지 않습니다.
- [피망 공식 고스톱 가이드](https://board-static.pmang.com/images/pmang/nabi/html/guide/gostop/gostop_2_2.html), [피망 공식 가이드 gostop5](https://board-static.pmang.com/images/pmang/nabi/html/guide/gostop5/gostop5_2_2.html): 손패와 더미패 처리 후 바닥패 전체 획득, 자신의 마지막 패에서는 판쓰리 피 보상 제외, 폭탄 후 두 번의 더미 전용 차례.

마지막 차례의 효과 표시, 폭탄 패스를 남은 차례로 계산하는 방식, 빈 바닥에서 쪽으로 회수했을 때의 판쓸 인정은 현재 구현의 처리 방식이며, 해당 세부 상황을 공식 문서가 명시한다고 단정하지 않습니다. 기존 쪽·따닥·뻑 회수의 마지막 패 처리 등 다른 규칙은 이번 변경 대상에 포함하지 않습니다. 한게임 고스톱의 자뻑 1피와 피망의 자뻑 2피처럼 서비스별 차이가 있으므로, 개별 보상표들을 조합해 중복 보상을 확정하지 않습니다.

## 충돌 방지

- `applyPansseul` / `applyGostopPansseul`은 완성된 턴 결과를 복사하여 이벤트와 피 보상만 더합니다. 같은 결과에 다시 적용해도 중복 추가되지 않습니다.
- 양쪽 화면의 `applyCompletedTurnResult`에서만 판쓸을 적용합니다. 일반 턴, 더미 전용 턴, 선택 완료, AI 턴이 이 경로를 통과합니다.
- 폭탄 손패의 중간 획득은 기존 `applyTurnResult`로 처리합니다. 이때 바닥이 비어도 판쓸은 판정하지 않습니다. 이후 더미까지 처리하고 바닥이 비었을 때만 판쓸이 발생합니다. 폭탄 자체의 보상과 애니메이션은 유지됩니다.
- 뻑이면 바닥에 세 장이 남으므로 판쓸이 아닙니다. 따닥이나 뻑 회수 후에는 남은 바닥을 기준으로 판정합니다.
- 기존 `specialEvents`와 `showSpecialEvents`를 통해 `쪽! + 판쓸!`처럼 표시합니다. `.special-effect`와 `GAME_SPEED.specialEffect`(900ms)를 재사용합니다.
- 획득·피 이동·효과 표시가 끝난 뒤 기존 GO/STOP 판단, 점수 계산, 정산, 다음 턴 처리가 실행됩니다. 점수·정산 함수와 CSS는 수정하지 않았습니다.

## 검증

Node 24에서 별도 패키지 설치 없이 실행합니다.

```sh
node --test tests/pansseul.test.mjs
npm run build
npm run lint
```

회귀 테스트는 두 모드의 모든 플레이어에 대해 일반 판쓸, 쪽/따닥/뻑 회수 중복, 뻑 제외, 임시 빈 바닥, 선택 대기, 폭탄/폭탄 패스, 마지막 차례, 피 부족·쌍피를 검증합니다. 점수 문턱과 2인 정산, 3인 고박 대납도 확인합니다.

중복 보상 테스트는 현재 프로젝트에서 확정한 하우스 룰의 회귀 테스트입니다. 합산 기대값이 유지되는지 검증하며, 공식 서비스의 규칙을 검증하거나 보증하는 테스트가 아닙니다.

브라우저에서 카드 이동·뒤집기·획득 애니메이션, 확대 보기, 모드 전환의 시각적 동작은 별도로 확인해야 합니다.
