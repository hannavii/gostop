# 온라인 관전

플레이어는 `Room.members`에 저장되며 좌석, 손패, 준비 상태와 재대결 투표를 가진다. 관전자는 별도 `Room.spectators`에 저장되며 좌석이 없다. 플레이어 정원과 방장 선정, 게임 진행 조건에 포함하지 않는다.

## 입장과 공개 범위

온라인 화면에서 방 코드를 입력하고 **관전하기**를 누른다. 닉네임은 필요 없다. `room:spectate({ roomCode })`는 match가 있는 진행 중 또는 종료된 방만 허용한다. 대기실에는 입장할 수 없다. 공개방과 비공개방 모두 정확한 코드로 관전한다. 기존 공개방 목록은 참가 가능한 공개 대기실만 표시하며 비공개방과 진행 중 방은 노출하지 않는다.

`room:spectator-state`는 `role: spectator`, `you: null`인 전용 상태다. 각 플레이어의 닉네임, 손패 장수, 획득패, 점수, GO/폭탄/흔들기 공개 상태, 바닥패, 공개된 카드, 남은 더미 장수, 현재 턴, 공개 행동 로그, 연결 상태, 턴 마감 시각 및 종료 정산을 포함한다.

`spectatorGameView`는 플레이어 serializer와 공통 공개 필드의 명시적 projection을 재사용한다. 관전자는 모든 손패가 빈 배열이고 `choice: null`, `specialOptions: []`, `canPlayHand: false`다. 실제 손패 ID, 숨겨진 더미 카드, pending 객체, 소켓 ID, 토큰, 토큰 해시 및 내부 타이머 객체는 포함하지 않는다. 플레이어용 상태와 이벤트는 유지한다.

## 권한과 생명주기

서버는 관전자 소켓의 준비, 시작, 재대결, 카드 제출, 매칭 선택, GO/STOP, 폭탄/흔들기/패스를 거부한다. 좌석은 클라이언트 입력이 아닌 소켓 소유권으로 결정한다. 현재 관전자 소켓은 플레이어 토큰으로 좌석을 탈취할 수 없다.

관전자에게 별도 무작위 토큰을 발급하고 해시만 서버에 저장한다. 브라우저 sessionStorage에는 방 코드, 토큰과 `role: spectator`를 보관한다. `room:spectator-resume`는 해당 방의 관전자 목록만 조회하고, 플레이어 `room:resume`는 플레이어 목록만 조회한다. 역할 간 토큰 전용과 다른 방 토큰 재사용은 불가능하다. 토큰은 소유자에게만 `room:session`으로 전달한다.

F5 및 일시 단절 후 60초 안에 복구한다. 기존 grace 상수를 재사용하지만 플레이어의 연결 대기, 좌석 예약, 방 종료 타이머는 만들지 않는다. 단절된 관전자 항목은 만료 시 복구가 거부되고 다음 관전 입장 때 정리된다. 중복 복구는 이전 소켓의 소유권을 먼저 취소하고 새 소켓으로 원자적으로 교체한다. 명시적으로 나가면 토큰을 즉시 폐기한다.

방당 `MAX_SPECTATORS_PER_ROOM = 20`으로 제한한다. 메모리와 상태 전송량을 제한하는 단순한 MVP 상한이다. grace 중인 연결도 포함하며, 만료 항목은 신규 입장 전에 제거한다. 관전자 입퇴장/복구/동기화는 플레이어 상태를 재전송하거나 게임 revision, 로그, 턴 deadline을 변경하지 않는다. 게임 상태 변경 후에는 관전자에게도 새 공개 상태를 전송한다.

종료 결과를 볼 수 있고 플레이어 전원 동의로 재대결이 시작되면 같은 방에서 다음 판을 계속 본다. 관전자는 투표하지 않는다. 플레이어 이탈/복구 만료로 방이 닫히면 관전자에게도 종료를 알린다. 서버 재시작 후에는 메모리 기반 방과 토큰이 소멸한다.

## 화면과 검증

2인/3인 모두 좌석 순서의 중립적인 플레이어 패널과 바닥패를 표시한다. 모든 손패는 뒷면과 장수만 표시하며 획득패 상세, 공개 로그, 턴 타이머, 연결 상태, 종료 정산과 나가기를 제공한다. 플레이어 행동 UI와 재대결 투표는 없다.

`npm run test:spectator`는 실제 Socket.IO의 직렬화 결과, 역할별 토큰, 위조 행동 거부, 중복 복구, 입퇴장 시 플레이어 상태/타이머 불변과 재대결 관전을 검사한다. `tests/e2e/spectator.spec.ts`는 2인/3인 실시간 진행, F5, 단절 중 플레이, 다음 판 관전과 360/375/390/412px 너비를 검사한다.
